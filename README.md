
# 🔦 Pocketbeam

### A Flashlight, But a Different One.

Is a flashlight, but a different one. **3 leds, a buzzer and darknees detectors.**

Exactly what we need for those nights when the power cuts.

**A manual control**, for when u need to have fun.

**Powered, by 2 aa**, this packs a punch.

This is custom built by me **IN kicad**.

### ⚡ What's Inside?

It includes **resistors, sensors, leds, capcacitors, switches** and a lot of my **blood sweat and tears**.
