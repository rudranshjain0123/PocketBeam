# PocketBeam


A flashlight right?
Is a flashlight, but a different one. 3 leds, a buzzer and even a darkness detector!

Exactly what we need for those nights when the power cuts.

A MANUAL CONTROL for when u need to have fun.
Powered by 2 aa, this packs a punch.
This is custom made by me in kicad.
# Whats INSIDE
It includes resistors, a capacitator, a detector, switches etc.
